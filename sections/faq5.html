Project data seperti apa yang biasa kamu kerjakan?

Saya biasa mengerjakan data cleaning, exploratory data analysis, reporting, dashboard design, dan penyusunan insight untuk kebutuhan bisnis maupun presentasi.

Tools apa yang paling sering kamu gunakan untuk analisis data?

Tools yang paling sering saya gunakan adalah Excel, SQL, Power BI, Tableau, Python, dan spreadsheet tools untuk pengolahan maupun pelaporan data.

Apakah kamu bisa membuat dashboard interaktif?

Ya. Saya bisa membuat dashboard interaktif yang menampilkan KPI, filter, perbandingan data, dan visual utama agar hasil analisis lebih mudah dipahami.

Apakah hasil analisis bisa dijelaskan dengan bahasa yang mudah dipahami?

Bisa. Saya berusaha membuat hasil analisis tidak hanya benar secara teknis, tetapi juga jelas, ringkas, dan mudah dipahami sehingga hasilnya dapat digunakan untuk presentasi maupun membantu proses pengambilan keputusan.

Apakah kamu terbuka untuk kolaborasi atau freelance project?

Ya. Saya terbuka untuk kolaborasi, pembuatan dashboard, portfolio project, dan pekerjaan analisis data skala kecil sampai menengah.
